# Java DSA (Data Structures & Algorithms)

A beginner-friendly repository for Java fundamentals and Data Structures & Algorithms (DSA) practice.  
This project contains basic Java topics, control structures, loops, and sample DSA problems to strengthen core programming skills.

## 📌 About

This repository is created to understand Java basics and gradually move into more complex Data Structures & Algorithms concepts.  
It includes examples and practice code on core Java concepts, structured in easy-to-follow folders.

## 📂 Repository Structure

- **basic/**: Basic Java concepts and syntax.
- **conditionals/**: Conditional statements (`if`, `else`, `switch`).
- **controlFlow/**: Control flow statements.
- **loop/**: Iteration and loops (`for`, `while`, `do-while`, patterns).
- **methods/**: Java methods and functions.
- **arraysAndStrings/**: Working with arrays and strings.
- **oops/**: Object-Oriented Programming concepts.
- **exceptionHandling/**: Handling exceptions in Java.
- **recursion/**: Recursion concepts and problems.
- **dsa/**: Data Structures and Algorithms implementations and problems.
  - `arrayList/`: ArrayList data structure implementation.
  - `arrays/`: Array based questions and logic.
  - `hashSet/`: HashSet implementation and problems.
  - `hashmap/`: HashMap implementation and problems.
  - `linkedHashMap/`: LinkedHashMap data structure.
  - `linkedHashSet/`: LinkedHashSet data structure.
  - `linkedList/`: LinkedList implementation and problems.
  - `priorityQueue/`: PriorityQueue data structure.
  - `queue/`: Queue implementation and problems.
  - `stack/`: Stack data structure implementation.
  - `strings/`: String based questions and logic.
  - `treeMap/`: TreeMap data structure.
  - `treeSet/`: TreeSet implementation and problems.
